# SIGNATURE-MAIL-TEAM-ANEKDOTE
Dossier rassemblant l'ensemble des fichiers HTML et hébergement des signatures de mail Anekdote

## Signatures

- [Emma LAHOREAU — EMMA L](EMMA%20L/README.md), 450 × 148 px.

Le GIF original `impact-makers.gif` reste à la racine. Les versions adaptées,
les photographies et les paramètres de chaque personne sont dans son dossier.

Pour créer une déclinaison : dupliquer le dossier d'une personne, modifier
`signature.json`, puis lancer `python3 scripts/build_signature.py "NOUVEAU DOSSIER"`.
Installer au préalable les dépendances avec `python3 -m pip install -r requirements.txt`.
Les instructions détaillées sont dans le dossier de la signature.
